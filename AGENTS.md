# Alcance de este repositorio

Este repositorio es un laboratorio de pruebas técnicas. Su código actual implementa un prototipo de valoración de cartas, pero **no** representa una preferencia general del propietario ni un modelo de referencia para otros proyectos.

- Trabajar exclusivamente con el objetivo y los requisitos de la tarea en curso.
- No asumir que nuevos desarrollos deben tratar sobre TCG, Pokémon, Magic, afiliación o monetización.
- No trasladar metodología, arquitectura, diseño, datos ni criterios de este repositorio a otros proyectos salvo que se solicite expresamente.
- Conservar el comportamiento del prototipo existente cuando se trabaje específicamente en él.
- No presentar este repositorio como una instrucción global, perfil del usuario o fuente de preferencias para otras conversaciones.
